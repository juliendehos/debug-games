
# piebill

## Description

Implémentation du jeu [Pie Bill Gates (Windows game,
1998)](https://www.youtube.com/watch?v=4tkgXdmJLVI) (en hommage à [Bill Gates
Pie in Face](https://www.youtube.com/watch?v=iK6SS8CXYZo)).

## Build & run

```
sudo apt-get install -y libudev-dev libvorbis-dev libflac-dev libsdl2-dev libsdl2-image-dev libsdl2-ttf-dev
nix-shell
cmake -B build
cmake --build build -j 8
```
